Should the vet X-ray first, or go straight to surgery?

■ decision node ● chance node ▲ outcome (terminal) node ✓ recommended path

🐾 Buddy — 3-year-old Labrador

Buddy is brought in with sudden vomiting and lethargy after a day of chewing on toys in the yard. The vet suspects an intestinal foreign body. Two options are on the table.

This worked example uses one set of sample numbers. The interactive exercise randomizes these numbers each time, so a student's version will use different figures — the method is what stays the same.

✓ Recommended option: A — X-ray first

Its expected cost (฿13,500) is lower than going straight to surgery (฿17,900) — the X-ray fee is small next to the cost of an unnecessary exploratory surgery, so it pays off on average even though it delays treatment slightly when the result is positive.

Worked calculation

  1. Option A — X-ray first: 0.60 × ฿18,500 + 0.40 × ฿6,000 = ฿13,500
  2. Option B — Straight to surgery: 0.55 × ฿17,000 + 0.45 × ฿19,000 = ฿17,900
  3. Compare: ฿13,500 (Option A) < ฿17,900 (Option B) → recommend Option A — X-ray first.
